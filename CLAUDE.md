# Rules for Claude in this repo

1. **Read-only until approved.** Do not edit, create or delete any file until the user has approved a plan for that change. Start by reading and proposing a plan; make changes only after a clear go-ahead.
2. **Commit locally only.** You may commit locally after approved changes, but never push, open or merge a pull request, create branches on GitHub, or write to GitHub in any other way unless the user explicitly asks for it in that conversation. When work is ready, say that it is committed locally and ask whether to push.
3. **No Claude attribution.** Never add `Co-Authored-By: Claude`, `Claude-Session:` links, "Generated with Claude Code" or any other Claude/Anthropic attribution to commits, pull requests or comments. Commits are authored by the user.
4. **No Copilot or other bot authors** in commits either.
