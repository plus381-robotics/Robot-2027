# docs — zajednička dokumentacija

Ono što važi za ceo robot, a ne za jedan uređaj. Dokumentacija pojedinačnog uređaja ide u njegov `README.md`.

| Fajl | Sadržaj |
|---|---|
| `podesavanje-pi.md` | log book konfiguracije RPi 4 (eksport iz Claude Doc-a "Podešavanje Pi") |
| `arhitektura/` | dijagrami povezivanja (Excalidraw eksport: `.excalidraw` + `.png`) |
| `protokol.md` | specifikacija poruka (kada se definiše; format okvira je u `protocol/README.md`) |

Excalidraw dijagrame čuvati i kao `.excalidraw` (može da se menja) i kao `.png` (vidi se direktno na GitHub-u).
